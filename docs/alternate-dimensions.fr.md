# Dimensions alternatives

[English](alternate-dimensions.md) · [Français](alternate-dimensions.fr.md)

Le portage Fabric 26.2 fournit `immersive_portals:skyland`, `bright_skyland`, `chaos`, `void` et `bright_void` dans le registre natif de dimensions de Minecraft. Aucun datapack supplémentaire ni installation externe de DimLib n’est nécessaire. L’[API de dimensions, les commandes et les modèles](dimension-library.fr.md) de DimLib sont adaptés en interne ; sa licence Apache-2.0 et ses attributions sont conservées dans [licenses](../licenses/DimLib-NOTICE.txt).

`enableAlternateDimensions` vaut `true` par défaut. Au chargement d’un monde, le mod ajoute les définitions absentes avant l’assemblage des couches de registres du serveur et les inclut dans les paramètres de génération sauvegardés. Les définitions sauvegardées et les datapacks restent prioritaires, ce qui préserve les générateurs existants. Régler l’option sur `false` empêche la création automatique des valeurs par défaut au chargement ; cela ne supprime ni les dimensions sauvegardées, ni leurs chunks, les définitions des datapacks ou la possibilité d’ajouter explicitement des dimensions par les commandes, les modèles, les empilements ou l’API.

Les skylands natifs utilisent la graine du monde et sauvegardent ce choix avec leur générateur. Les datapacks peuvent fournir un `seed` fixe ; `use_world_seed: true` sélectionne plutôt la graine du serveur à l’initialisation. Le terrain chaos conserve le générateur régional volontairement non déterministe de l’amont. Les deux variantes vides utilisent un générateur plat vide. `void` utilise le type de dimension vanilla du monde principal, tandis que `bright_void` et `bright_skyland` utilisent `surface_type_bright`. Les dimensions dont le type est un type de surface du mod synchronisent leur météo avec celle du monde principal.

Les cinq dimensions sont proposées pour les empilements. Avant la mise à jour d’un empilement, ses dimensions alternatives manquantes sont créées par l’API interne. Les modèles `skyland`, `bright_skyland`, `chaos`, `void` et `bright_void` permettent aussi leur création explicite. Désactiver les valeurs par défaut automatiques ne désactive pas ces actions.

Les tests exclusivement GitHub vérifient la désactivation, la priorité des sauvegardes/datapacks, les variantes vides manquantes, les métadonnées de registre et les paramètres de génération sauvegardés. Les scénarios en jeu génèrent des chunks dans les cinq dimensions, rechargent leurs codecs et comparent le bruit des skylands à la véritable graine du monde. Une relance du serveur dédié avec `enableAlternateDimensions=false` vérifie que les dimensions sauvegardées et les blocs témoins subsistent. Les preuves exigées incluent `PORTAL_SMOKE_ALTERNATE_DIMENSIONS_OK`, `PORTAL_SMOKE_SKYLAND_WORLD_SEED_OK` et `PORTAL_SMOKE_DIMENSION_RELOAD_OK`. Il s’agit des assertions prévues, pas d’une affirmation que la révision actuelle les a réussies ; consulter le [passage GitHub Actions](port-26.2.fr.md) exact.
