# Minestom integration

[English](minestom.md) · [Français](minestom.fr.md)

The standalone Fabric repository does not build or distribute the Minestom server SDK or example application. Their implementation and documentation remain in [N4TH4NOT/immersive-portals-minestom](https://github.com/N4TH4NOT/immersive-portals-minestom/blob/67bf29333b82b0d6c594c65d84256c881f0182b4/docs/minestom.md).

The inherited client bridge and internal `portal-protocol` module are retained for wire compatibility. Their presence does not make this repository a Minestom server distribution. Server-side usage, authorization, gravity and API examples belong to the linked SDK guide.
