# Intégration Minestom

[English](minestom.md) · [Français](minestom.fr.md)

Le dépôt Fabric autonome ne compile ni ne distribue le SDK serveur Minestom ou son application d’exemple. Leur implémentation et leur documentation restent dans [N4TH4NOT/immersive-portals-minestom](https://github.com/N4TH4NOT/immersive-portals-minestom/blob/67bf29333b82b0d6c594c65d84256c881f0182b4/docs/minestom.fr.md).

Le pont client hérité et le module interne `portal-protocol` sont conservés pour la compatibilité du protocole. Leur présence ne fait pas de ce dépôt une distribution serveur Minestom. L’utilisation côté serveur, l’autorisation, la gravité et les exemples d’API appartiennent au guide du SDK lié ci-dessus.
