# Portal generation datapack

[English](README.md) · [Français](README.fr.md)

Optional examples for this fork. Download `example_custom_portal_gen.zip` from a successful [GitHub Actions run](https://github.com/N4TH4NOT/Immersive-Portals/actions), then install the ZIP when creating a world. Compilation and validation run only on GitHub Actions.

Rules live in [`data/i_am_namespace/immersive_portals/custom_portal_generation/`](data/i_am_namespace/immersive_portals/custom_portal_generation). The pack registers its own dimensions through vanilla datapacks; see [pack.mcmeta](pack.mcmeta) for the format. Back up existing worlds before changing dimension definitions. These examples do not replace validation of the mod's built-in alternate dimensions.
