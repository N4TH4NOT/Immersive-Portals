# Datapack de génération de portails

[English](README.md) · [Français](README.fr.md)

Exemples optionnels pour ce fork. Télécharger `example_custom_portal_gen.zip` depuis un [passage GitHub Actions réussi](https://github.com/N4TH4NOT/Immersive-Portals/actions), puis installer le ZIP à la création du monde. Les compilations et validations s’exécutent uniquement sur GitHub Actions.

Les règles figurent dans [`data/i_am_namespace/immersive_portals/custom_portal_generation/`](data/i_am_namespace/immersive_portals/custom_portal_generation). Le pack enregistre ses dimensions par datapack vanilla ; le format figure dans [pack.mcmeta](pack.mcmeta). Sauvegarder les mondes existants avant de modifier leurs définitions de dimensions. Ces exemples ne remplacent pas la validation des dimensions alternatives intégrées au mod.
